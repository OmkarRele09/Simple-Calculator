# 🧮 Simple Calculator in C

A beginner-friendly command-line calculator written in C.

The program takes two numbers and an arithmetic operator from the user and performs the selected calculation.

This project was built as part of my journey learning C programming and practicing conditional statements, user input, variables, and arithmetic operators.

## 📌 Features

- Addition
- Subtraction
- Multiplication
- Division
- Takes numbers and operators as user input
- Displays the calculated result

## 💻 Technologies Used

- C Programming
- Standard Input/Output (`stdio.h`)

## ▶️ How It Works

The program asks the user to enter:

1. First number
2. Second number
3. Arithmetic operator

The program then checks the operator using `if` / `else if` statements and performs the corresponding calculation.

### Supported Operators

| Operator | Operation |
|----------|-----------|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
